자투리 기도 앱 - 복구/통합 수정본

포함 기능
- 새 기도 심기
- 진행 중 기도만 일반 정원에 표시
- 기도하기: 기도 선택 → 준비 → 타이머 → 완료
- 기도 완료 시 growthPoints +1 및 성장 단계 자동 변경
- 식물 클릭 상세창
- 상세창에서 해당 기도로 바로 기도하기
- 기도 삭제
- 응답받은 기도로 옮기기
- 응답 기도는 일반 정원/기도하기/자라는 기도 개수에서 제외
- 응답 정원 별도 화면 및 따뜻한 색상
- 응답 정원에는 응답된 기도만 표시
- 식물 배치 지점을 화면 끝에서 안쪽/위쪽으로 조정

성장 기준
0 seed
1~2 sprout
3~5 seedling
6~9 bud
10~14 bloom
15+ full_bloom

PC에서 프로젝트 폴더를 열고 npm install 후 npm run dev 로 실행하세요.
